# ZiMovie Releases

Official ZiMovie installers and release notes. This public repository contains release artifacts only, never application source code.

Desktop clients starting with version 1.0.2 check the published stable releases here and offer an update when a newer installer is available for their platform. Installation is performed by the user.

- macOS: `ZiMovie_<version>_universal.dmg` for Intel and Apple Silicon.
- Windows: `ZiMovie_<version>_x64.exe` when a Windows build is available.
- Stable tag: `v<major>.<minor>.<patch>`.

Drafts and prereleases are not offered to users. Each platform uses the newest stable release with its completed installer asset. Upload and verify assets in a draft before publishing.
